# Abstract

The Real-Time Collaborative Document Editing System is a browser-based application for students who need to prepare group assignments together. It combines a React client, an Express REST API, MongoDB persistence and authenticated Socket.IO rooms. Users register and sign in, create private documents, invite registered collaborators, edit shared content and see presence and updates without refreshing. The backend uses a deterministic finite automaton to validate document editing, saving, and locking transitions. A document is reported as saved only after MongoDB confirms the write. The project also exposes a DFA simulator and an activity monitor sourced from actual HTTP and Socket.IO events. This document describes the design and implementation; runtime verification results are recorded separately and are not assumed in advance.
